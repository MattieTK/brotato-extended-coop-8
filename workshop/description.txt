Extends local coop from 4 to [b]8 players[/b]. Works with Steam Remote Play Together.

[h1]Features[/h1]
[list]
[*]Up to 8 players join on the character select screen, which becomes a 2x4 grid of player slots
[*]Weapon selection, the shop, level-up choices and the end-of-run screen are all split into a per-player 2x4 grid
[*]In game, the full (enlarged 1.5x) arena is always visible, with colour-tagged player stat strips running down both sides of the screen
[*]4 new player colours for players 5-8
[*]Full controller support for 8 gamepads, or 7 gamepads + keyboard
[/list]

[h1]Steam Remote Play Together[/h1]
Invite friends through the Steam overlay - their controllers appear as local ones, nothing else to set up.

Windows note: Xbox-type (XInput) controllers are limited to 4 by Windows itself. Controllers 5-8 need to be DirectInput-capable (PlayStation, Switch Pro and most generic pads are). If a 5th controller is not detected, try disabling Steam Input for Brotato in its Steam controller settings.

[h1]Saves[/h1]
Your normal progression save is shared with the unmodded game and untouched. Runs with more than 4 players are stored in a separate run file that the unmodded game never reads, so nothing breaks if you play without the mod mid-run - the 8-player run is simply resumed next time you play with the mod.

[h1]Compatibility[/h1]
Built for Brotato v1.1.15.4. This mod extends many UI scripts, so it may conflict with other mods that rework the coop interface. Runs with 4 or fewer players use the completely vanilla interface.

Not compatible with the older "Extended Coop" mod - unsubscribe from it if you have it.
